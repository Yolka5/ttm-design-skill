# Writing

The words are part of the design. Write like a smart friend explaining something plainly: direct, warm, no filler. The interface speaks as the product, never as "I".

## Mechanics

- Sentence case everywhere: buttons, headings, tabs, labels, menu items. Capitals only for names.
- No full stop on labels, buttons or headings. Helper text and descriptions do end with one.
- Use contractions: "can't", "you'll", "it's".
- Active voice, verb first: "Delete project", not "Project deletion".
- An ellipsis only means something is in progress: "Saving…".
- Write "and", not "&".
- No em dashes. Use a comma, a colon or a new sentence.

## Patterns

**Buttons.** A verb and what it acts on, one to three words: "Create project", "Export data". Never "OK", "Submit" or "Click to continue". In a confirm step, the button repeats the action: "Delete project", not "Yes".

**Errors.** What happened, then what to do, in one or two short sentences. "That name's already taken. Try another." No "Error:" prefix, no raw exception text, no blame.

**Empty states.** An invitation. The heading names the space ("Start your first calculation"), one line explains it, and the button is a verb. Skip "Nothing here yet".

**Confirmations.** Past tense, no fuss: "Saved", "Link copied". The message is the success, so it never says "successfully".

**Placeholders.** A real example of valid input: "name@team.com", "Kraken X60". Never repeat the label, and never put instructions only in a placeholder, since they vanish when typing starts.

**Links.** Say where they go: "Read the motor specs". Never "click here".

**Units and numbers.** Always show the unit, with a space: "12 V", "6.5 km". Round to what the reader can use.

## Words to skip

| Skip | Why | Instead |
| --- | --- | --- |
| successfully | The message already is the success | "File uploaded" |
| please | The interface is not asking a favour | "Enter a name" |
| click here, tap to | Link text should name the place | "View pricing" |
| simply, just, easy | It presumes, and stings when it is not easy | Cut it |
| seamless, unlock, leverage, empower | Filler | Say what it does |
| ! on system messages | Reads as shouting | "Settings saved" |

## Pronouns

"Your" for the reader's things: "Your projects", never "My projects". The interface never says "I". Errors address the reader: "Your session expired. Sign in again."
